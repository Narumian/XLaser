##builtin高速置換(未実装メモ。遅いと測れてから作る)
StandardLibraryのスクリプトが正。ホストのネイティブ実装は、そのreadだけを高速に置き換えるもの。

仕様
- ネイティブは入力定義を持たない。入力はスクリプトのヘッダが唯一の正で、ネイティブはreadの中身だけを提供する。
- 置換は正規ファイルの内容ハッシュに結ぶ。ユーザーが複製して書き換えるとハッシュが変わり、ただのJSとして動く。IDやVERSIONだけでは結ばない。
- ネイティブとスクリプトの出力はFloat32の許容誤差内で一致すること。
- ブラウザに出るのはStandardLibraryの1つだけ。builtinという置き場所は作らない。

作り方
1. ベンチで遅いと確認する。まずスクリプトを速い書き方(reserve/commit、batch)に直し、それでも足りないときだけ作る。
2. ホスト側でネイティブのreadを書き、正規ファイルのハッシュで登録する。
3. 同じ入力と時刻でスクリプトとネイティブを走らせる差分テストを足す。
4. スクリプトを編集したらハッシュが変わるので、ネイティブは自動で外れる。必要なら作り直す。
